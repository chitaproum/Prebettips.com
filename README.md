# PreBetTips - Forebet Clone Rebuild

This repository contains the rebuilt web application for PreBetTips following the updated dark-mode UI layout.

## File Structure
- `index.html`: Core HTML structure.
- `styles.css`: Dark-theme layout styling matching the reference layout.
- `data.js`: Mock match data and statistics.
- `fetch-data.js`: Asynchronous data retrieval layer.
- `app.js`: Dynamic table rendering and interactive filters.
